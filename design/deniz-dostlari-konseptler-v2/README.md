# Deniz Dostları — üç konsept

Yerleşik Imagegen ile üretilmiş PNG yön araştırması. Önce kullanıcı konsepti seçer; ardından ekranlar ve UI parçaları tek tek hazırlanır. Bu aşamada fonksiyonel Unity UI kurulmaz.

1. Sade denizci: açık zemin, lacivert yazı, mercan aksan, ferah kartlar.
2. Koleksiyon defteri: kâğıt dokusu, mürekkep çizgileri, sıcak mat renkler.
3. Modern çizgi: koyu teal zemin, krem kartlar, kalın çizgili karakterler.

Bunlar görsel yön seçimidir; sayaçlar, yıldızlar ve ekran metinleri seçilen yönde detaylandırılır.
